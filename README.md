# ESOF0152-Agile-Project
Project for ESOF-0152 agile software development.
The project is a web app that can search and find the nutritional value of foods, and recipes with instructions. 
Originally developed in a group using agile methodologies (the overwhelming majority by me), using Jira ticket tracking.
I forked then cloned the old project to update it using new API's since the old ones changed.
Site is live at: https://capable-hamster-9558c0.netlify.app/
